# Nera Brand Kit — Slide Edition

This kit is designed for 16:9 presentations, Demo Day thumbnails, product screenshots and project reports.

## Quick use

1. In PowerPoint, choose **Insert → Pictures → This Device** and insert an SVG from `logo/`.
2. SVG files stay sharp at every size. In recent PowerPoint versions, right-click the SVG and choose **Convert to Shape** when you need to recolor individual parts.
3. Use `templates/nera-slide-cover.svg` as the opening-slide background and `templates/nera-slide-content.svg` for regular content slides.
4. Keep screenshots real and readable. Use coral only to highlight one important point per slide.

## Logo files

- `logo/nera-logo-primary.svg`: horizontal logo for light backgrounds.
- `logo/nera-logo-reverse.svg`: horizontal logo for dark backgrounds.
- `logo/nera-symbol.svg`: standalone app/avatar mark.
- `logo/nera-symbol-light.svg`: standalone mark for dark backgrounds.
- `logo/nera-logo-mono.svg`: single-color version for printing or sponsor pages.

The symbol combines an **N**, a home roof and an open doorway. The coral square is the human-confirmation point: AI recommends, real data and Sale confirm.

## Color system

| Role | Hex | Use |
|---|---:|---|
| Nera Forest | `#14372F` | Main backgrounds, headline, CTA |
| Deep Forest | `#09241E` | High-contrast opening/closing slides |
| Living Sage | `#DDE9E1` | Panels, cards, secondary backgrounds |
| Warm Canvas | `#F7F4ED` | Main slide background |
| Signal Coral | `#E26D4F` | Important numbers, active state, confirmation point |
| Ink | `#10261F` | Body text |
| Soft Gray | `#6D7A75` | Supporting text |
| White | `#FFFFFF` | Text on dark backgrounds |

Recommended balance: **70% Warm Canvas / 20% Forest / 10% Sage + Coral accents**.

## Typography

- Preferred: **Be Vietnam Pro** for titles and **Inter** for body/UI.
- PowerPoint-safe fallback: **Aptos Display** for titles and **Aptos** for body.
- Title: 36–44 pt, Semibold/Bold, line spacing 0.95–1.05.
- Body: 18–22 pt, Regular/Medium, line spacing 1.15–1.25.
- Caption: 11–14 pt.
- Avoid all-caps paragraphs. All-caps is reserved for short section labels.

## Slide rules

- 16:9 layout, minimum 48 px safe margin; recommended 72–96 px.
- One key message per slide and no more than three supporting points.
- Use real Nera screenshots inside rounded frames; do not add decorative AI robots or magic sparkles.
- Use soft shadows only: black at 10–14% opacity, blur 24–36 px.
- Use 16–24 px rounded corners for cards.
- Keep the logo clear space equal to the coral square on all sides.
- Minimum horizontal logo width: 140 px on a 1920×1080 slide.
